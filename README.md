# 🧪 Лабораторная работа №2

**Тема:** построение ETL-процесса с Apache Spark и экспорт результатов в PostgreSQL, MongoDB и ClickHouse

## Описание

В работе собирается полноценный ETL-пайплайн: данные загружаются из CSV, обрабатываются в Spark, преобразуются в модель «звезда» и отправляются в три разные СУБД. Всё разворачивается через Docker Compose, чтобы инфраструктура поднималась в один шаг. 🚀

Лабораторная ориентирована на практику: как собрать полный цикл обработки данных и как подключать различные хранилища в одном проекте.

## ▶️ Как запустить

### 1. Поднять инфраструктуру

```bash
cd BigDataAnalytics_Lab2
docker-compose up -d
```

Появятся сервисы: Jupyter + Spark, PostgreSQL, MongoDB, ClickHouse.

### 2. Открыть Jupyter Notebook

Перейти: [http://localhost:8888](http://localhost:8888)
Файл: `etl_lab2.ipynb`

### 3. Выполнить ETL

В ноутбуке последовательно выполняются шаги:

* загрузка CSV в Spark;
* первичная обработка;
* сохранение «сырых» данных в PostgreSQL;
* построение модели «звезда» (dim_таблицы + fact_sales);
* агрегации (топы, продажи по измерениям);
* экспорт витрин в PostgreSQL, MongoDB, ClickHouse.

## ⚠️ Возможные проблемы и как их решить

### Контейнеры не стартуют

Проверить Docker Desktop или логи:

```bash
docker-compose logs <service>
```

### Jupyter недоступен

Проверить статус:

```bash
docker-compose ps
```

### PostgreSQL не подключается

Порт может быть занят → перезапуск сервисов:

```bash
docker-compose down
docker-compose up -d
```

### CSV не читается

Проверить путь: `data/all_mock_data.csv`.
